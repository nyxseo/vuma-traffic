# Introduction

[Jago Traffic](https://traffic.jagocode.id) comes with various advanced features to increase traffic automatically with safer, more realistic, and more flexible methods.

## Core Features  

- **Multi-Platform Compatibility**: Can run on multiple platforms for maximum flexibility in increasing traffic.
- **Advanced Multi-Threading**: Run multiple tasks simultaneously on multiple platforms with threading techniques for high efficiency.
- **Organic Search Traffic**: Increase website ranking organically by targeting search engines through natural searches.
- **Automated User Interaction**: Automatically imitate user interactions, such as scrolling, clicking, and navigation, to increase engagement.
- **Customizable Advanced Interaction**: Adjust user interaction patterns according to your needs, including visit duration, number of clicks, and pages accessed.
- **Human-Like Behavior**: Read content with natural patterns like humans to avoid detection as a bot.
- **Interaction Time Control**: Control page reading time to resemble real user behavior.
- **Smart Worker**: Intelligent automated system that adjusts work patterns based on target traffic and best performance.
- **Auto Switch**: Automatically switch between fingerprint mode, traffic source, or other methods to increase traffic variety and avoid detection.
- **Auto Ad Click**: Increase interaction with ads through an automatic click system on ads displayed on the page.
- **Auto Report**: Send automatic worker performance reports to registered WhatsApp numbers every 1 hour.
- **Advanced Proxy Integration**: Supports various types of proxies (HTTP, SOCKS, Residential, etc.) to hide identities and access various locations.
- **Verified Browser Fingerprint**: Uses verified browser fingerprints to avoid security system detection.
- **Dynamic Fingerprint Rotation**: Dynamically changes fingerprints to create identity variations and increase anonymity.
- **Device Simulation**: Adjusts the device used (desktop, mobile, tablet) for a realistic browsing experience.
- **Custom User-Agent**: Sets the User-Agent according to the device and browser used in the traffic simulation.
- **Verified Traffic Sources**: 20 categories are available with millions of quality site lists for more credible traffic sources.
- **Custom Traffic Sources**: Allows users to specify traffic sources such as social media, search engines, or direct visits.
- **Ad Network Compatibility**: Can be used for various types of ads such as AdSense, Adsterra, MgId, Monetag, and other platforms without violating policies.
- **Comprehensive Documentation**: Complete guide to help users understand Jago Traffic configuration and features easily.
- **Plugin Support**: Allows feature expansion with additional plugins according to user needs.

## Installation

```bash
npm i -g jagotraffic
jagotraffic install
```

## How to run

```bash
jagotraffic login
jagotraffic start
```

For more complete documentation, please visit the following link [https://docs.jagocode.id](https://docs.jagocode.id/docs/jago-traffic/getting-started/installation)
